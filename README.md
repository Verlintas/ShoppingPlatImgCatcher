# ShoppingPlatImgCatcher 电商图片采集器

一键批量下载京东 / 淘宝天猫 / 拼多多指定商品的**主图、SKU 图、详情长图**，自动还原原图分辨率，按商品归档，并生成下载报告。

> 适用场景：个人素材整理、竞品调研、店铺装修素材收集。请控制抓取频率并遵守各平台服务条款，勿用于商业爬取或数据倒卖。

## 功能

- **一键全自动**：导入商品表 → 自动搜索三个平台的旗舰店/同款 → 人工确认（可跳过）→ 批量下载图片
- **三种输入方式**：Excel/CSV 导入、粘贴链接、关键词搜索
- **原图还原**：自动去掉京东 `s450x450_jfs`、淘宝 `_430x430q90.jpg`、拼多多 `imageMogr2` 等缩略参数，取最大分辨率
- **按商品归档**：`序号_商品名_商品ID/主图|详情图|SKU图/`，文件名自带平台、序号与分辨率
- **断点续传**：SQLite 记录每个 URL 与文件哈希，中断重跑不重复下载；相同图片自动去重
- **风控监督程序**：检测验证码/滑块/风控页自动暂停，弹出可见浏览器等待人工验证后自动恢复
- **拼多多兜底**：稳定性不足时切换人工选品半自动模式
- **下载报告**：任务汇总 + 图片明细两份 Sheet，含失败原因

## 平台支持度

| 平台 | 自动化程度 | 说明 |
|---|---|---|
| 京东 | 全自动 | 搜索页/商品页结构稳定 |
| 淘宝/天猫 | 全自动（需登录） | 偶发滑块验证，由监督程序处理 |
| 拼多多 | 监督 + 半自动兜底 | 反爬最强，必要时人工点选商品 |

## 快速开始（Windows 免安装版）

1. 到 [Releases](../../releases) 下载 `ShoppingPlatImgCatcher-win64.zip` 并解压
2. 双击 `ShoppingPlatImgCatcher.exe`
3. 首次启动会自动下载浏览器内核（约 150MB，可在设置中配置国内镜像）
4. 打开「设置与登录」，依次点击京东 / 淘宝 / 拼多多登录，在弹出的浏览器中完成登录（登录态会持久保存）
5. 回到「导入商品」导入数据 →「匹配确认」核对店铺 →「下载任务」开始下载

## 商品表格式

| 商品名称 | 规格/型号 | 京东链接 | 淘宝链接 | 拼多多链接 | 店铺名 | 备注 |
|---|---|---|---|---|---|---|
| Apple iPhone 16 | 256G 黑色 | https://item.jd.com/xxx.html | | | Apple产品京东自营旗舰店 | |

- 链接列可留空：留空平台会在「自动匹配」时按 `商品名称 + 规格` 搜索
- 表头别名兼容：商品名/名称/标题、jd/京东、tb/淘宝/天猫、pdd/拼多多 等

## 从源码运行

```bash
python 3.11
pip install -r requirements-dev.txt
python -m playwright install chromium   # 或首次运行时自动下载
python main.py
```

## 架构

```
app/
├── core/        配置、数据模型、SQLite、事件总线、日志
├── platforms/   Playwright 适配器（jd / taobao / pdd）+ 持久化浏览器 + 风控检测
├── services/    原图还原、命名、Excel、匹配评分、下载器、报告
├── engine.py    匹配与下载引擎（并发、限速、重试、续传、监督）
└── gui/         PySide6 桌面界面（导入 / 匹配 / 任务 / 设置）
```

平台改版时只需修改 `app/platforms/` 下对应适配器的选择器与提取逻辑。

## 常见问题

- **提示需要登录/频繁弹验证**：到「设置与登录」重新登录对应平台；建议并发调低、延迟调大
- **拼多多搜不到结果**：使用「拼多多人工选品」按钮，人工点选后自动接管下载
- **浏览器内核下载失败**：在设置中填入镜像（默认 `https://cdn.npmmirror.com/binaries/playwright`）或配置代理后重启
- **下载的图仍是缩略图**：该平台可能未提供更大尺寸，`manifest.json` 中保留了原始 URL 便于核查
